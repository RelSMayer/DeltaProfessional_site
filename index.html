01 / DELTA CNC

Від файлу вишивки до руху п'ялець — одна система.

DELTA CNC розробляється як повний тракт керування обладнанням: підготовка даних на Raspberry Pi → SPI V2 → real-time контролер STM32 → планування руху → STEP/DIR → XY-механіка.

01

Сучасний HMIІнтерфейс оператора на Raspberry Pi / Avalonia та підготовка даних вишивки.

02

Real-time motion controlОкремий STM32-контролер відповідає за планування та точне виконання руху XY.

03

Синхронізація зі швейною головоюРух п'ялець виконується з урахуванням положення голки та безпечного вікна руху.

04

Робочі режими JOG / TRACE / STITCHРучне позиціонування, обведення контуру та виконання стібків використовують єдиний motion stack.

02 / СТАТУС РОЗРОБКИ

Від архітектури — до перевірки реальної вишивки.

Базовий програмно-апаратний тракт уже працює. Зараз DELTA CNC переходить до практичної валідації на реальному обладнанні та завершення програмного забезпечення.

CONTROLReal-time motionPlanner, Motion та StepScheduler працюють як єдиний активний тракт.
SYNCБезпечний рух XYРеалізовано рух з урахуванням фази голки та фізичного вікна.
STITCHКороткий тест пройденоБазове виконання короткої STITCH-послідовності підтверджено.
NEXTРеальна вишивкаНаступний етап — тести з п'яльцями, тканиною, стабілізатором та ниткою.
03 / КОМПЛЕКТАЦІЯ

Конфігурація залежить від того, що вже є у замовника.

DELTA CNC не прив'язується до однієї фіксованої комплектації. Наявна швейна машина, стіл або придатна механіка можуть бути використані після перевірки та суттєво зменшити кінцеву вартість.

CONFIG / FULL

Повна система

Варіант для нового робочого місця, де комплект обладнання формується під задачу замовника.

Використання сумісної швейної машини, столу або механічних вузлів замовника після перевірки.

04 / DELTA CNC UPGRADE

Справну механіку не обов'язково замінювати.

Для DELTA Professional з придатною механічною базою, зокрема систем на алюмінієвому профілі, планується модернізація: зберегти раму, напрямні, XY-механіку та інші справні вузли, а застаріле керування замінити системою нового покоління.
